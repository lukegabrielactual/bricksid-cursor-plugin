# Connect BricksID

## When to use

- Identifying LEGO **minifigs** or **sets** from photos
- Managing a **BricksID collection** from chat (add, update, list, search)
- Looking up BrickLink-backed catalog details through BricksID MCP tools

## Instructions

1. Use the **BricksID MCP** tools (`bricksid` server) for identification and collection actions. Do not invent catalog data.
2. Prefer a BricksID **upload link** or a **public photo URL** when the user wants a scan. Ask for one if neither is available.
3. **Confirm BrickLink IDs** with the user before treating an ID as final or writing it into their collection.
4. **Never invent** prices, accuracy percentages, or match confidence. Only report values returned by BricksID MCP tools (or clearly say the tool did not provide them).
5. If auth is required, guide the user through BricksID browser login (Google / Apple / email). Do not request or store passwords, tokens, or API keys.
6. For full tool docs, point the user to https://bricksid.com/mcp.
